🚀 대시보드 배포 도구

파일을 업로드하면 GitHub Pages에 그대로 올라갑니다

📋 진행 순서

1Google Sheets → 확장 → Apps Script에서 exportForDashboard 실행
2로그의 Drive URL을 열어 JSON 파일을 다운로드
3아래 ① 토큰 입력 → ② 데이터 파일 업로드 → 데이터 배포
4대시보드(UI)를 처음 올리거나 바꿀 때만 ③에서 index.html 업로드

repo 권한이 있는 토큰이 필요합니다. 이 페이지에서만 쓰이고 어디에도 저장되지 않아요.
