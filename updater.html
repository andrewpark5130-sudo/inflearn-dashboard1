🚀 대시보드 자동 배포 도구

Apps Script 로그 데이터를 붙여넣으면 GitHub Pages에 자동으로 반영돼요

📋 사용 방법

1Google Sheets → 확장 프로그램 → Apps Script → exportSummary 실행
2하단 실행 로그 전체 복사 (Ctrl+A → Ctrl+C)
3아래 입력창에 붙여넣기 후 배포하기 클릭
41~2분 후 대시보드 URL에서 확인

💡 토큰은 이 페이지에서만 사용되며 어디에도 저장되지 않아요

💡 타임스탬프(오전 11:02:20 정보)나 청크 헤더([1/2])가 섞여 있어도 자동으로 처리돼요
